# SGR Chat Memory System

## 📝 Описание

Добавлена система постоянной памяти для чат-сессий в SGR Trading Agent, позволяющая сохранять и восстанавливать историю диалогов между пользователем и агентом.

## 🔧 Функциональность

### Модели данных (models.py)
- `CreateChatSession` - создание новой чат-сессии
- `SaveChatMessage` - сохранение сообщения в сессию  
- `GetChatHistory` - получение истории чата с фильтрацией

### База данных (sgr_trading_agent.py)
- `DB.data["sessions"]` - словарь всех чат-сессий
- `DB.data["chat_messages"]` - сообщения по session_id
- Методы: `create_chat_session()`, `save_chat_message()`, `get_chat_history()`

### Интеграция с Chainlit (trading_demo_app.py)
- Автоматическое создание сессий при старте
- Сохранение всех пользовательских и системных сообщений
- Отображение истории предыдущих чатов при запуске приложения

## 🎯 Использование

### В SGR агенте:
```python
# Создание сессии
session = create_chat_session("Анализ AAPL", "user_123", "stock_analysis")

# Сохранение сообщения
save_chat_message(session_id, "user", "Проанализируй AAPL", {"symbol": "AAPL"})

# Получение истории
history = get_chat_history(session_id, limit=50, message_types=["user", "assistant"])
```

### В Chainlit веб-интерфейсе:
- Сессии создаются автоматически
- Сообщения сохраняются прозрачно для пользователя
- История отображается при старте новой сессии

## 📊 Структура данных

### Сессия:
```json
{
  "session_id": "session_1_abc123",
  "session_name": "Trading Analysis - 2025-09-06 15:57",
  "user_id": "chainlit_user",
  "session_type": "trading_analysis",
  "created_at": "2025-09-06T15:57:39",
  "last_activity": "2025-09-06T15:57:39",
  "message_count": 5,
  "active": true
}
```

### Сообщение:
```json
{
  "message_id": "msg_1",
  "session_id": "session_1_abc123",
  "message_type": "user",
  "content": "Проанализируй AAPL",
  "metadata": {"symbol": "AAPL", "task_type": "analysis"},
  "timestamp": "2025-09-06T15:57:39"
}
```

## 🔍 Типы сообщений
- `user` - сообщения пользователя
- `assistant` - ответы агента
- `system` - системные уведомления
- `tool` - результаты выполнения инструментов

## 💡 Особенности

### SGR-совместимость:
- Следует паттерну простой in-memory структуры
- Совместимо с существующими торговыми правилами
- Поддерживает фильтрацию и поиск

### Chainlit интеграция:
- Автоматическое создание сессий
- Прозрачное сохранение истории
- Отображение предыдущих диалогов
- Уведомления о состоянии памяти

### Производительность:
- Быстрый доступ через словари
- Лимиты на количество сообщений
- Возможность фильтрации по типам

## 🚀 Демонстрация

Запустите Chainlit интерфейс:
```bash
uv run chainlit run trading_demo_app.py
```

При старте вы увидите:
- Уведомление о создании новой сессии
- Историю предыдущих чатов (если есть)
- Автоматическое сохранение всех сообщений

## 📈 Преимущества

1. **Постоянная память** - диалоги не теряются между сессиями
2. **Контекст** - агент может ссылаться на предыдущие разговоры
3. **Аналитика** - возможность анализа паттернов пользователей
4. **SGR-совместимость** - интегрируется с торговыми правилами
5. **Простота** - минимальная настройка, максимальная функциональность

Система готова к использованию в продакшене с возможностью дальнейшего расширения до внешних баз данных.
